# WorldEdit (ワールドエディット)

**WorldEdit** は、Minecraft（Spigot / Paper / Purpur）サーバーにおいて、広範囲のブロック編集・整地・建築・地形造成を瞬時に行える世界で最も有名な建築支援プラグインです。
「木の斧」を使った直感的な範囲選択、ブロックの一括設置・置換（`//set`, `//replace`）、建物のコピー＆ペースト、球体・円柱などの幾何学図形生成、ブラシツールによる自然な山や洞窟の造形など、手作業では何日もかかる作業を数秒で完了させることができます。

:::warning

**編集時点**での情報を元にしています。  
今後のバージョンアップで仕様変更が行われる可能性があります。

:::

## 導入手順

1. **サーバーを停止する**  
   コンソールで `stop` を実行し、サーバーを安全に停止します。

2. **jar ファイルをダウンロードする**  
   サーバーの Minecraft バージョンに対応した `worldedit-bukkit-x.x.x.jar` をダウンロードします。

3. **plugins フォルダへ配置する**  
   ダウンロードした `.jar` ファイルをサーバーの `plugins/` フォルダに入れます。

4. **サーバーを起動する**  
   サーバーを起動すると、`plugins/WorldEdit/` ディレクトリと設定ファイル（`config.yml`）が自動生成されます。

5. **導入確認**  
   ゲーム内で `//wand` を実行し、インベントリに「木の斧（選択ツール）」が付与されれば正常に動作しています。

## 主なコマンド一覧

:::tip
 コマンドの先頭文字について  
WorldEdit のコマンドの多くは、通常コマンドと区別するためにスラッシュが2つ（`//`）で始まります。一部のナビゲーション系コマンド（`/jumpto` など）はスラッシュ1つです。
:::

### 1. 範囲選択と基本操作
| コマンド | 説明 |
| :--- | :--- |
| `//wand` | 範囲選択ツール（デフォルトは「木の斧」）を取り出します。 |
| `//pos1` / `//pos2` | 現在立っている足元を「開始地点 (Pos1)」/「終了地点 (Pos2)」に設定します。 |
| `//hpos1` / `//hpos2` | 視線の先（クロスヘアが当たっているブロック）を Pos1 / Pos2 に設定します。 |
| `//size` | 現在選択されている範囲のブロック総数を表示します。 |
| `//expand <ブロック数> [方向]` | 選択範囲を指定した方向（`up`, `down` 等）へ拡大します。 |
| `//contract <ブロック数> [方向]` | 選択範囲を指定した方向へ縮小します。 |

### 2. ブロック編集・置換
| コマンド | 説明 |
| :--- | :--- |
| `//set <ブロック>` | 選択範囲内をすべて指定したブロックで埋め尽くします。 |
| `//replace [元ブロック] <新ブロック>` | 特定のブロックだけを別のブロックに置き換えます（元ブロック省略で空気以外すべて）。 |
| `//walls <ブロック>` | 選択範囲の外周に壁を作成します。 |
| `//outline <ブロック>` | 選択範囲の外枠（中空の箱）を作成します。 |
| `//undo [回数]` | 直前の操作を取り消します（最大履歴数は設定による）。 |
| `//redo [回数]` | 取り消した操作をやり直します。 |

### 3. コピー・ペースト・変形
| コマンド | 説明 |
| :--- | :--- |
| `//copy [-e]` | 自分の相対位置を含めてクリップボードにコピーします（`-e` で額縁や防具立ても含む）。 |
| `//paste [-a]` | コピーした建築を貼り付けます（`-a` で空気ブロックを除外して貼り付け）。 |
| `//rotate <角度>` | クリップボード内の建築物を時計回りに回転します（`90`, `180`, `270`）。 |
| `//flip [方向]` | 建築物を鏡写し（反転）にします（`up`, `north` 等）。 |
| `//schem save <名前>` | 選択範囲を `.schem` ファイルとして保存します。 |
| `//schem load <名前>` | 保存した `.schem` ファイルをクリップボードに読み込みます。 |

### 4. 図形生成・整地・ブラシ
| コマンド | 説明 |
| :--- | :--- |
| `//cyl <ブロック> <半径> [高さ]` | 足元に円柱を作成します。 |
| `//sphere <ブロック> <半径>` | 足元を中心に球体を作成します（中空にする場合は `//hsphere`）。 |
| `//pyramid <ブロック> <サイズ>` | ピラミッドを作成します（中空にする場合は `//hpyramid`）。 |
| `//drain <半径>` | 周囲の水や溶岩を除去します。 |
| `//fixwater <半径>` | 水流をすべて水源化して平らに整えます。 |
| `//brush sphere <ブロック> <半径>` | 持っているアイテムに球体ブラシツールを付与します。 |
| `//brush smooth <半径>` | 地形を滑らかにするスムースブラシを付与します。 |
| `//mask [ブロック]` | ブラシの影響を受けるブロックを制限します。 |

## 権限ノード (Permissions)

WorldEdit はサーバー負荷や荒らしリスクが非常に高いため、**一般プレイヤーには権限を与えず、管理者や信頼できるビルダーのみに付与**するのが鉄則です。

```yaml title="LuckPerms 権限付与例" showLineNumbers {1,6-9,13-14}
# 管理者向け（全権限）
worldedit.*

# ビルダー向け（個別権限付与の例）
# 基本操作・選択
worldedit.wand
worldedit.selection.pos
worldedit.selection.hpos
worldedit.selection.expand

# 設置・置換・アンドゥ
worldedit.region.set
worldedit.region.replace
worldedit.history.undo
worldedit.history.redo

# クリップボード・ブラシ
worldedit.clipboard.*
worldedit.brush.*
```

## config.yml の日本語訳・おすすめ設定

設定ファイル（`plugins/WorldEdit/config.yml`）内の重要項目です。サーバークラッシュを防ぐためのリミット設定が含まれています。

```yaml title="plugins/WorldEdit/config.yml" showLineNumbers {3,7,12,17-18}
# ----------------------------------------------------
# 1. 1回の操作で変更できる最大ブロック数（最重要）
# ----------------------------------------------------
# サーバーのスペックに合わせて設定します（-1 で無制限）
# クラッシュ防止のため、一般ビルダー向けには 50000 〜 100000 程度を推奨
max-blocks-changed:
  default: 50000
  maximum: -1

# ----------------------------------------------------
# 2. アンドゥ（//undo）の最大履歴数
# ----------------------------------------------------
# 履歴を増やしすぎるとサーバーのメモリ（RAM）を圧迫します
history:
  size: 15
  expiration: 10

# ----------------------------------------------------
# 3. 選択ツール（Wand）のアイテム変更
# ----------------------------------------------------
# デフォルトは木の斧（minecraft:wooden_axe）
wand-item: 'minecraft:wooden_axe'

# ----------------------------------------------------
# 4. コンパスによる瞬間移動（ナビゲーション）
# ----------------------------------------------------
# コンパスを持って左クリックで通過、右クリックで視線先へテレポート
navigation-wand:
  item: 'minecraft:compass'
  max-distance: 100
```

## 実践：知っておくと役立つ応用テクニック

### 1. ランダムな比率でブロックを混ぜる（グラデーション・自然な床）
カンマとパーセンテージを使うことで、複数のブロックをランダムに配置できます。

```text title="コマンド入力例" showLineNumbers {1,4}
# 石 70% と 丸石 30% の割合で埋め尽くす
//set 70%stone,30%cobblestone

# 草ブロックの上に自然な花畑を作る
//replace #top 80%air,10%dandelion,10%poppy
```

### 2. 空気ブロックを含めずにペーストする（`-a` オプション）
通常、`//copy` して `//paste` すると建物の周囲の空気ブロックも一緒に貼り付けられ、周囲の既存地形を削ってしまいます。

```text title="コマンド入力例" showLineNumbers {2}
# -a を付けると、クリップボード内の「空気」が無視されて既存の地形を壊しません
//paste -a
```

### 3. ブラシで山を作る（Mask との組み合わせ）
木の棒などのアイテムを持った状態で実行します。

```text title="コマンド入力例" showLineNumbers {2,5}
# 半径 4 の丸石球体ブラシを作成
//brush sphere cobblestone 4

# 空気中には出さず、既存の地面にだけ重ねて盛り上げる
//mask stone,dirt,grass_block
```

## よくある質問・注意点 (FAQ)

### Q1. 木の斧で普通にブロックを壊そうとすると Pos1 になってしまいます
**解決策**: `//toggleeditwand` を実行すると、木の斧による範囲選択機能の有効/無効を切り替えることができます。

### Q2. 巨大な範囲を `//set` したらサーバーが固まって（タイムアウトして）落ちました
**原因**: 一度に数百万ブロックを変更しようとすると、サーバーのスレッドが停止します。  
**解決策**:
- `config.yml` の `max-blocks-changed` に上限値を設定してください。
- 10万ブロックを超える大規模な整地・編集を日常的に行う場合は、非同期（マルチスレッド）で処理してサーバーを落とさない派生プラグイン **[FastAsyncWorldEdit (FAWE)](https://www.spigotmc.org/resources/fast-async-worldedit.13932/)** の導入を検討してください。

### Q3. `//schem save` したファイルはどこに保存されますか？
**保存先**: サーバーフォルダ内の `plugins/WorldEdit/schematics/` に `.schem` 形式で保存されます。別サーバーへの移行時もこのファイルをコピーするだけで建築を移動できます。
