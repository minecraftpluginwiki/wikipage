# 記事用テンプレート
プルリクエストなどで記事を作成する際の**基本的な**記事テンプレートは下記とします。  
項目は必要に応じて増やしても減らしても構いません。

## ファイル名
ファイル名は `プラグイン名` にしてください。  
おおまかなジャンルごとにフォルダを作成しているので、そのフォルダに入れてください。  
管理者向けであれば、`admin`、経済系であれば`ecology`など。  
おおまかなジャンルがなければ作成していただいても構いません。

## ヘッダー部分
`title`、`description`、`tags`は以下のルールに従ってください。

``` text showLineNumbers
---
title: プラグイン名
description: プラグインの説明(一言)
tags: [プラグイン名,開発者,対応ソフトウェア(spigotやpaperなどをカンマ区切りで),ジャンル]
---
```

## ジャンル別のフォルダを作成する場合
おおまかなジャンルフォルダがない場合は、作成しても構いません。  
フォルダを作成した際には `_category_.json` が必要です。

``` markdown showLineNumbers
{
  "label": "ジャンル名",   # おおまかなジャンル名(サイドバーに表示されます!)
  "position": 2,  # サイドバーの並び順(他のジャンルと被らないようにしてください!!)
  "link": {    # [plugins/フォルダ]にアクセスしたときに表示されます
    "type": "generated-index",
    "title": "ジャンル名", # ジャンルの名称(～～プラグインとか～～向けとか)
    "description": "ジャンルの概要", # ジャンルの概要を一言
    "slug": "/plugins/フォルダ名" 
  }
}
```

`#`は削除して、編集してください。
