# Minecraft Plugins Wikiへようこそ
SpigotやPaperサーバで使える各種プラグインの設定やコマンド、権限ノード、日本語化手順をまとめるWikiです。  

## まずは入れるべきプラグイン
サーバを立てたら最初に入れておきたいプラグインのまとめです。

| プラグイン名 | 用途 | 難易度 | 解説 |
| :--- | :--- | :---: | :--- |
| **[LuckPerms](./plugins/core/luckperms)** | 権限（パーミッション）管理のデファクトスタンダード | ★★★ | [解説へ](./plugins/admin/luckperms) |
| **[CoreProtect](./plugins/security/coreprotect)** | 荒らし対策・ブロック設置破壊ログの巻き戻し（Rollback） | ★★☆ | [解説へ](./plugins/admin/coreprotect) |
| **[WorldEdit](./plugins/building/worldedit)** | コマンドで大量のブロックを一括設置・整地 | ★★☆ | [解説へ](./plugins/admin/worldedit) |
| **[WorldGuard](./plugins/security/worldguard)** | スポーン地点や街の土地保護・PVP無効化 | ★★★ | [解説へ](./plugins/admin/worldguard) |
